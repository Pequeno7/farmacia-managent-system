# Pharmacy Management System

Sistema de gestão de farmácia desenvolvido como projeto de software para praticar a criação de soluções informáticas aplicadas à gestão de uma farmácia.

## Objetivo

Organizar o desenvolvimento de um sistema que apoie processos de gestão de uma farmácia. Os módulos, regras de negócio e tecnologias serão documentados à medida que o código-fonte e os requisitos forem integrados neste repositório.

## Documentação

A documentação funcional e técnica será acrescentada após a recuperação e revisão da implementação original, incluindo:

- Funcionalidades disponíveis
- Tecnologias e arquitetura
- Modelo de dados
- Requisitos e instruções de instalação
- Exemplos de utilização e testes

## Estado

**Código-fonte por integrar/rever.** Este README identifica o propósito do projeto; não significa que os módulos listados como possíveis componentes estejam implementados.
